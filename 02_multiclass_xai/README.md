# Phase 2: Multiclass XAI

This folder contains the MaFaulDa multi-class XAI pipeline split into modular files.

## Run

From the repository root:

```powershell
python 02_multiclass_xai\run_phase2.py
```

## Inputs

- Dataset root: `data/raw_mafulda`

## Outputs

- Final model artifact: `models/02_multiclass_xai/`
- Feature cache artifacts: `playground_models/02_multiclass_xai/`
- Plots and explainability outputs: `figures/02_multiclass_xai/`
